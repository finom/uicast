# Packages

The published packages of **uicast**. Each folder has its own README.

| Package | What it is |
| --- | --- |
| [`@uicast/core`](core) | The engine, without React: entry format, reactive scopes, error classification, prompt builders. |
| [`@uicast/react`](react) | The React binding: provider, renderer, skeletons, an error boundary per element. |
| [`@uicast/expr`](expr) | The expression language and its interpreter. Works on its own. |
| [`@uicast/shadcn-catalog`](shadcn-catalog) | A reference catalog over shadcn/ui and Radix, each component with its definition. |
| [`@uicast/streamdown`](streamdown) | A Streamdown plugin: documents inside ```` ```uicast ```` fences in Markdown chat replies. |

The docs site is in [`docs/`](../docs), the example apps in [`examples/`](../examples).

# ui-fired Next.js demo

Admin for **Deskware**, a tiny office-gear store (customers, products, orders in a local SQLite DB). Pages and chat answers are generated by an LLM as ui-fired JSONLines against `@ui-fired/shadcn-catalog` and rendered live — no build step per generation.

## Run

```bash
npm install                                   # repo root
npm run db:migrate -w @ui-fired/nextjs-demo
npm run db:seed -w @ui-fired/nextjs-demo
npm run dev -w @ui-fired/nextjs-demo
```

Put `AI_GATEWAY_API_KEY` in `packages/nextjs-demo/.env.local` (plain model ids resolve through the Vercel AI Gateway). Optional: `AI_MODEL`, `AI_MAX_OUTPUT_TOKENS`.

## Things to try

The point to notice: the generated UIs are **apps, not pictures** — forms validate and submit, buttons mutate the DB through the domain tools, destructive actions ask for confirmation, and every widget bound to the same state moves in sync.

**Create page** — full pages, streamed onto `/pages/[id]`:

- `Order dashboard with quick status actions`
- `Order intake terminal for phone orders`
- `Product catalog with an add-product form`
- `Customer manager with edit and delete`
- `Fulfillment board for pending orders`

**New chat** — answers that render as live UI (the ` ```uifired ` fence via `@ui-fired/streamdown`):

- `How much did we earn this month?`
- `Quick tool to create an order`
- `Help me clear the pending queue`
- `Price editor for the catalog`
- `Cleanup tool for cancelled orders`

Try the chat cockpit one: ship an order and watch the KPIs, the chart, and the queue all move from a single click. Use the Rendered/Source switcher on chat blocks to see the emitted JSONLines.

# Getting started

The packages ship **raw TypeScript** — no build step, and a public API surface
that is still settling. Install them from npm (they are in beta, under the
`beta` dist-tag — pin the versions):

```sh
npm install @uicast/core@beta @uicast/react@beta @uicast/shadcn-catalog@beta @uicast/streamdown@beta
```

- **`@uicast/core`** — the framework-agnostic engine.
- **`@uicast/react`** — the React binding.
- **`@uicast/shadcn-catalog`** — the ready-made component catalog (optional —
  you can define your own).
- **`@uicast/streamdown`** — the Streamdown plugin for chat replies (optional).

Let your bundler transpile the raw source — in Next.js:

```ts
// next.config.ts
const nextConfig = {
  transpilePackages: [
    "@uicast/core",
    "@uicast/react",
    "@uicast/shadcn-catalog",
    "@uicast/streamdown",
  ],
};
```

No path aliases are needed — the packages resolve through their `exports`
maps like any npm dependency.

## A document is a stream of lines

Each line is one element — a `ComponentEntry` — and the lines form a tree by
**key reference**: an element lists its children's `key`s, and the children are
separate lines.

```jsonl
{ "key": "root", "component": "Card", "children": ["title"] }
{ "key": "title", "component": "Text", "props": { "literal": { "children": "Hello" } } }
```

The engine mounts them in order, so a parent always arrives before the children
it references. Mount this with the React binding's [`<Renderer>`](/react/renderer),
passing the catalog's renderers and any host `functions` your expressions call —
the [`/demo`](/demo) source is a complete, working setup.

# Getting started

Install the packages from npm (they are in beta, under the `beta` dist-tag —
pin the versions):

```sh
npm install @uicast/core@beta @uicast/react@beta @uicast/shadcn-catalog@beta @uicast/streamdown@beta
```

- **`@uicast/core`** — the render engine: the JSONLines model, an expression
  evaluator that validates code for safety, and the reactive proxy state store.
  React-free.
- **`@uicast/react`** — the React binding that mounts a document.
- **`@uicast/shadcn-catalog`** — a plug-and-play catalog built on shadcn/ui,
  for starting fast; real apps typically define their own catalog (optional).
- **`@uicast/streamdown`** — the Streamdown plugin: entries ride inside
  `uicast` code fences in Markdown chat replies (optional).

The packages ship compiled ESM with type declarations and resolve through their
`exports` maps like any npm dependency — no bundler configuration or path
aliases needed.

## A document is a stream of lines

Each line is one element — a `ComponentEntry` — and the lines form a tree by
**key reference**: an element lists its children's `key`s, and the children are
separate lines.

```jsonl
{ "key": "root", "component": "Card", "children": ["title"] }
{ "key": "title", "component": "Text", "props": { "literal": { "children": "Hello" } } }
```

The engine mounts them in order, so a parent always arrives before the children
it references. Mount this with the React binding's [`<EntriesRenderer>`](/react/renderer),
passing the catalog's renderers and any host `functions` your expressions call.

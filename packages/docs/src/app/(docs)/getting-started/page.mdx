# Getting started

The full framework is consumed as a **git dependency** for now, and the
consumer bundles its raw TypeScript source: no build step, and a public API
surface that is still settling. (The core engine alone is also on npm as
[`uicast`](https://www.npmjs.com/package/uicast) — the repo install below
covers everything, engine included.) Install the repo — the repo package is
named `uicast-repo`, and its root `dependencies` mirror every runtime dep, so
one install brings them along:

```sh
npm install github:finom/uicast
```

Let your bundler transpile the raw source — in Next.js:

```ts
// next.config.ts
const nextConfig = {
  transpilePackages: ["uicast-repo"],
};
```

Then map the package specifiers — bare `uicast` for the engine, scoped
`@uicast/*` for the rest — into the installed tree with `tsconfig` path
aliases (Next.js resolves imports through them too):

```jsonc
// tsconfig.json
{
  "compilerOptions": {
    "paths": {
      "uicast": ["./node_modules/uicast-repo/packages/uicast/src/index.ts"],
      "uicast/prompt": ["./node_modules/uicast-repo/packages/uicast/src/prompt/index.ts"],
      "@uicast/react": ["./node_modules/uicast-repo/packages/react/src/index.ts"],
      "@uicast/react/*": ["./node_modules/uicast-repo/packages/react/src/*"],
      "@uicast/shadcn-catalog/events": ["./node_modules/uicast-repo/packages/shadcn-catalog/src/events/index.ts"],
      "@uicast/shadcn-catalog/defs": ["./node_modules/uicast-repo/packages/shadcn-catalog/src/defs.ts"],
      "@uicast/shadcn-catalog/impls": ["./node_modules/uicast-repo/packages/shadcn-catalog/src/impls.ts"],
      "@uicast/shadcn-catalog/default-components": ["./node_modules/uicast-repo/packages/shadcn-catalog/src/default-components/index.ts"],
      "@uicast/shadcn-catalog/ui/*": ["./node_modules/uicast-repo/packages/shadcn-catalog/src/components/ui/*"],
      "@uicast/streamdown": ["./node_modules/uicast-repo/packages/streamdown/src/index.ts"],
      "@uicast/streamdown/prompt": ["./node_modules/uicast-repo/packages/streamdown/src/prompt/index.ts"]
    }
  }
}
```

## A document is a stream of lines

Each line is one element — a `ComponentEntry` — and the lines form a tree by
**key reference**: an element lists its children's `key`s, and the children are
separate lines.

```jsonl
{ "key": "root", "component": "Card", "children": ["title"] }
{ "key": "title", "component": "Text", "props": { "literal": { "children": "Hello" } } }
```

The engine mounts them in order, so a parent always arrives before the children
it references. Mount this with the React binding's [`<Renderer>`](/react/renderer),
passing the catalog's renderers and any host `functions` your expressions call —
the [`/demo`](/demo) source is a complete, working setup.

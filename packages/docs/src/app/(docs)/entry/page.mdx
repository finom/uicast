# Component Entry Format

A **uicast** document is a stream of JSONLines, and each line is one
**component entry** — the flat JSON object that describes a single element of
the document. An entry names the `component` to render, gives it an identity
(`key`), and optionally carries its `props`, initial state (`seed`), visibility
(`hidden`), event handlers (`callbacks`), and `children`. The engine reads
entries in order and mounts them into a tree by key reference.

It is not a new language. The envelope is [**plain JSONLines**](https://jsonlines.org/) — one JSON object
per line, nothing custom — and the dynamic fields (`props`, `hidden`, `each`,
and the `expr` of a `seed` or `callback`) are **ordinary JavaScript
expressions**, evaluated against the document's reactive scopes. There is no
grammar to learn beyond JSON and the JavaScript you already write — which is
what keeps the format small enough for a model to emit fluently, in very few
tokens.

[**Entry fields**](/entry/fields) is the field-by-field reference for that
object: every key an entry can carry, what it holds, and which deeper mechanism
it draws on.

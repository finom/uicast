# Component Entry Format

A **uicast** document is a stream of JSONLines, and each line is one **component
entry**: a flat JSON object describing one element. It names the `component`,
carries a `key`, and optionally `props`, `seed`, `hidden`, `callbacks`, and
`children` — plus `each` / `as` / `keyBy` when the line repeats. The engine
mounts them into a tree by key reference.

There is no new language here: the dynamic fields are ordinary
[expressions](/expr) over the document's scopes.

Each of those fields, used once:

```jsonl
{"key":"task-card","component":"Card","props":{"literal":{"title":"Tasks"}},"seed":[{"set":"scopes.root.tasks","expr":"listTasks()"}],"children":["task-rows","empty-note","refresh"]}
{"key":"task-rows","component":"Typography","each":"scopes.root.tasks","as":"task","keyBy":"id","props":{"expr":"({ text: scopes.task.title })"}}
{"key":"empty-note","component":"Typography","hidden":"scopes.root.tasks.length > 0","props":{"literal":{"text":"No tasks yet"}}}
{"key":"refresh","component":"Button","props":{"literal":{"text":"Refresh"}},"callbacks":{"onClick":[{"set":"scopes.root.tasks","expr":"listTasks()"}]}}
```

`task-card` is the root, since no `children` array mentions it. `task-rows`
repeats one `Typography` per task, `empty-note` disappears once tasks exist,
and `refresh` refetches on click.

[Entry fields](/entry/fields) is the reference for every key an entry can
carry.

# Reference catalog

`@uicast/shadcn-catalog` is a reference catalog: 128 components over
shadcn/Radix, each a def/impl pair in its own directory under
[`src/uicast-catalog`](https://github.com/finom/uicast/tree/main/packages/shadcn-catalog/src/uicast-catalog).
**uicast** does not need it. Use it as is, take some of its groups, or copy its
layout for your own catalog.

## Install

```bash
npm install @uicast/shadcn-catalog@beta
```

Import its stylesheet once, in your global CSS:

```css
@import "@uicast/shadcn-catalog/catalog.css";
```

`catalog.css` holds the utilities the components use and no palette: each rule
reads a CSS variable (`var(--card)`), so your theme applies. An app without its
own shadcn setup imports `theme.css` first, for preflight and the shadcn
palette:

```css
@import "@uicast/shadcn-catalog/theme.css";
@import "@uicast/shadcn-catalog/catalog.css";
```

## Groups

Each group is two modules: `@uicast/shadcn-catalog/<group>/defs` for the prompt
and `@uicast/shadcn-catalog/<group>/impls` for the renderer.

| group | components | for example |
| --- | --- | --- |
| `all` | 128 | every group below |
| `layout` | 17 | card, grid, flex row and column, tabs, accordion |
| `content` | 35 | heading, typography, badge, avatar, timeline, alert, map |
| `data` | 11 | table, data grid, virtual list, kanban board, org chart |
| `charts` | 16 | bar, line, pie, area, scatter, funnel, sankey |
| `forms` | 35 | field, input, select, date picker, file upload, button |
| `navigation` | 7 | sidebar, navigation menu, command menu, breadcrumb, pagination |
| `overlays` | 7 | modal, confirm dialog, drawer, popover, tooltip, dropdown menu |
| `essential` | 30 | picked from the groups: enough for a page, at about a quarter of the full catalog's prompt |

## How a host uses it

A module exports only its components, by name, so `import * as` gives the whole
group. The prompt gets the definitions:

```ts
import { getComponentsPartialPrompt } from "@uicast/core/prompt";
import * as catalogDefs from "@uicast/shadcn-catalog/all/defs";

getComponentsPartialPrompt({ definitions: Object.values(catalogDefs) });
```

The renderer gets the matching implementations:

```tsx
import * as catalogImpls from "@uicast/shadcn-catalog/all/impls";

const impls = Object.values(catalogImpls);

<RendererProvider implementations={impls} evaluator={evaluator}>
  <EntriesRenderer entries={entries} />
</RendererProvider>;
```

The `defs` modules import no React, so the prompt can be built on the server.

### Some groups

Spread the groups you want, the same way on both sides:

```ts
import * as layoutDefs from "@uicast/shadcn-catalog/layout/defs";
import * as chartDefs from "@uicast/shadcn-catalog/charts/defs";

const definitions = [...Object.values(layoutDefs), ...Object.values(chartDefs)];
```

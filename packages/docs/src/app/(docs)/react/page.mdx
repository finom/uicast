# React

The React binding, exported from `@uicast/react`:

- [Renderer](/react/renderer) — `<RendererProvider>` and `<EntriesRenderer>`,
  the mount point that turns entries into live UI. Wiring an app? Start here.
- [Component implementation](/react/impl) — `createComponentImplementation`,
  the React half of a component pair. For building your own catalog components.

The model-facing half — [definitions](/def), the [entry format](/entry),
[expressions](/expr) — is framework-agnostic and lives in
[`@uicast/core`](/api-ref#uicastcore). Reading the stream is too. React only comes in at the
end, when you pass the entries to `<EntriesRenderer>`.

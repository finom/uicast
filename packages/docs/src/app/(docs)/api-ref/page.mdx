# API reference

Five packages. Each publishes compiled ESM plus type declarations, so no bundler
configuration is needed.

| Package | What it is |
| --- | --- |
| [`@uicast/core`](#uicastcore) | The engine: entry types, reactive scopes, the prompt builders. No React. |
| [`@uicast/expr`](#uicastexpr) | The expression evaluator: closed grammar, runtime membrane, budget. No uicast imports. |
| [`@uicast/react`](#uicastreact) | The React binding: the renderer and the implementation factory. |
| [`@uicast/shadcn-catalog`](#uicastshadcn-catalog) | 150 ready components as def/impl pairs, over shadcn/ui. |
| [`@uicast/streamdown`](#uicaststreamdown) | Renders `uicast` fences inside a Markdown chat reply. |

## `@uicast/core`

The engine, framework-agnostic. See [Core concepts](/concepts).

### `@uicast/core` — index module

| Export | What it does |
|---|---|
| `createComponentDefinition(def)` | Builds a [component definition](/def). |
| `createProxyScope(initial?)` | One reactive [scope](/entry/state): a shallow proxy over a bag of fields that emits the field on write. |
| `buildElementsByKey(entries)` | Folds an entry array into a `key → entry` map, applying [partial replacement](/entry/fields#partial-replacement). |
| `streamJsonLines<T>(source)` | Async generator over a byte or string stream, yielding each parseable JSON line and skipping prose and partial lines. |
| `isComponentEntry(value)` | Runtime guard: is this parsed JSON an entry? |
| `EntryError` | The classified failure every fault arrives as. See [Error recovery](/error-recovery). |

Types: `ExpressionEvaluator` — re-exported from `@uicast/expr`. Also
`ComponentEntry`, `ComponentListEntry`, `ComponentDefinition`, `CombinedSpec`,
`ValueSource`, `ValueSourceAssignment`, `CallbackValueSourceAssignment`,
`ReactiveProxy`, `UrlPolicy`, `EntryErrorReason`, `EntryFault`.

There is also `@uicast/core/internal` — the engine plumbing the React binding
runs on. It carries **no semver guarantee** — don't build on it.

### `@uicast/core/prompt` — prompt module

The [prompt-partial builders](/prompt). Each takes one options object.

| Export | Emits |
|---|---|
| `getCommonInstructionsPartialPrompt({ maxListItems?, note? })` | The output contract — entries, keys, partial replacement — plus the expression context: the names an [expression](/expr) can see (`scopes` / `evt` / `currentValue`). The language itself is `getExpressionsPartialPrompt()` below — compose both. |
| `getScopePartialPrompt({ kind, approxElements?, note? })` | How much to build on this surface. |
| `getComponentsPartialPrompt({ definitions, note? })` | The component menu, from your [definitions](/def). Callback payloads with a `$id` hoist into `# Common Events` automatically. |
| `getExpressionsPartialPrompt({ maxLength?, note? })` | The `# JavaScript Expressions` block — syntax, methods, globals, and the length limit. Filled from [`@uicast/expr`](#uicastexpr)'s own tables. |
| `getFunctionsPartialPrompt({ functions, note? })` | Call signatures, from your [host functions](/functions). |
| `getEditRequestPrompt({ request, missingKeys? })` | A user-turn message for an [edit](/prompt#edit-and-recovery-turns). |
| `getErrorRecoveryPrompt({ failures })` | A user-turn message naming the elements that failed. |

Types: one options type per builder (`ComponentsPromptOptions`,
`ScopePromptOptions`, …), plus `RenderFailure`. Every `get*PartialPrompt`
builder — here and in the other packages — takes `note?`: host-specific
context rendered as that section's trailing `## Note`, verbatim.

## `@uicast/expr`

The [expression language](/expr), standalone — nothing **uicast**-specific in
it.

| Export | What it does |
|---|---|
| `Evaluator` | The interpreter: `eval`, `compile`, `validate`, `memberReads`. `functions` binds [host functions](/functions) at construction, which is what lets a call be checked before it runs; `budget` sets the ceilings. |
| `ExpressionEvaluator` | The interface both evaluators implement and **uicast** types against: `eval`, `compile`, `validate`, `memberReads`, `functions`. Implement it to plug in an evaluator of your own, for any language. |
| `ExpressionError` | Every refusal and fault, with a `reason`. |

Types: `EvaluatorOptions`, `EvaluatorContexts`,
`BudgetOptions`, `ExpressionFacts`, `ExpressionErrorReason`, and
`StandardToolV0` with the `StandardSchemaV1` / `StandardJSONSchemaV1` interfaces — copied
verbatim from `standard-tool` and the Standard Schema spec; a tool built with
`standard-tool` satisfies it as-is.

There is also `@uicast/expr/internal`, shared with core and the passthrough
package. It carries **no semver guarantee** — don't build on it.

## `@uicast/expr-passthrough`

The same language run by the engine through `new Function` — for documents
from a trusted author; see [Two evaluators](/expr#two-evaluators).

| Export | What it does |
|---|---|
| `PassthroughEvaluator` | `Evaluator`'s options minus `budget`, same methods; its own class, built on `@uicast/expr`'s static checks. Needs CSP `unsafe-eval`. |

Types: `PassthroughEvaluatorOptions`.

## `@uicast/react`

The React binding. Re-exports nothing from core — import from both.

| Export | What it does |
|---|---|
| `<RendererProvider>` | Host side: implementations, the evaluator (with the host functions on it), fallback UI, and the shared `root` scope. See [Renderer](/react/renderer). |
| `<EntriesRenderer entries>` | Mounts a document. Memoized on the array reference. |
| `createComponentImplementation({ def, render, placeholder? })` | The React half of a component pair. See [impl](/react/impl). |

Types: `ComponentImplementation`, `RenderContext`, `RendererProviderProps`,
`EntriesRendererProps`, `FallbackComponents`, `PlaceholderComponentProps`,
`ConfirmComponentProps`, `ErrorComponentProps`, `InitFn`, `InitContext`, `Scopes`.

## `@uicast/shadcn-catalog`

A ready catalog, and a demo of what one looks like. See
[Getting started](/getting-started).

| Entry point | What it holds |
|---|---|
| `@uicast/shadcn-catalog/defs` | `allDefinitions`, plus every definition by name (`CardDef`, `ButtonDef`, …) — pass to `getComponentsPartialPrompt`. |
| `@uicast/shadcn-catalog/impls` | `allImplementations`, plus every implementation by name — pass to `<RendererProvider>`. |
| `@uicast/shadcn-catalog/events` | `mouseEventSchema`, `keyboardEventSchema` — the shared event payloads the catalog's callbacks reuse. See [Shared events](/def#shared-events). |
| `@uicast/shadcn-catalog/fallback-components` | `ConfirmModal` and `RenderError`, for [`fallbackComponents`](/react/renderer). |
| `@uicast/shadcn-catalog/ui/*` | The 37 underlying shadcn components (`/ui/button`, `/ui/skeleton`, …). |
| `@uicast/shadcn-catalog/catalog.css` | Every utility the components use, with no palette — your `@theme` supplies all of it. |
| `@uicast/shadcn-catalog/theme.css` | Optional baseline: preflight plus the shadcn palette. |

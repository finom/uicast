# API reference

Five packages, published as compiled ESM with type declarations.

| Package | What it is |
| --- | --- |
| [`@uicast/core`](#uicastcore) | The engine: entry types, reactive scopes, the prompt builders. No React. |
| [`@uicast/expr`](#uicastexpr) | The expression evaluator: closed grammar, runtime membrane, budget. No **uicast** imports. |
| [`@uicast/react`](#uicastreact) | The React binding: the renderer and the implementation factory. |
| [`@uicast/shadcn-catalog`](#uicastshadcn-catalog) | A reference catalog: 128 def/impl pairs over shadcn/ui. |
| [`@uicast/streamdown`](#uicaststreamdown) | Renders `uicast` fences inside a Markdown chat reply. |

## `@uicast/core`

See [Core concepts](/concepts).

### `@uicast/core` — index module

| Export | What it does |
|---|---|
| `createComponentDefinition(def)` | Builds a [component definition](/def). |
| `createProxyScope(initial?)` | One reactive [scope](/entry/state): a shallow proxy over its fields. A write emits the field. |
| `buildElementsByKey(entries)` | Folds entries into a `key → entry` map, applying [partial replacement](/entry#partial-replacement). |
| `streamJsonLines<T>(source)` | Async generator over a byte or string stream. Yields each line that parses as JSON; skips prose and partial lines. |
| `isComponentEntry(value)` | Runtime guard: is this parsed JSON an entry? |
| `EntryError` | The classified error every fault arrives as. See [Error recovery](/error-recovery). |

Types: `ComponentEntry`, `ComponentListEntry`, `ComponentDefinition`,
`CombinedSpec`, `ValueSource`, `ValueSourceAssignment`,
`CallbackValueSourceAssignment`, `ReactiveProxy`, `UrlPolicy`,
`EntryErrorReason`, `EntryFault`, and `ExpressionEvaluator` (re-exported from
`@uicast/expr`).

`@uicast/core/internal` is plumbing for the React binding, with **no semver
guarantee**. Don't build on it.

### `@uicast/core/prompt` — prompt module

The [prompt-partial builders](/prompt). Each takes one options object.

| Export | Emits |
|---|---|
| `getCommonInstructionsPartialPrompt({ maxListItems?, note? })` | The output contract (entries, keys, partial replacement) and the names an [expression](/expr) can see: `scopes`, `evt`, `currentValue`. The language itself is `getExpressionsPartialPrompt()`; use both. |
| `getScopePartialPrompt({ kind, approxElements?, note? })` | How much to build on this surface. |
| `getComponentsPartialPrompt({ definitions, note? })` | The component menu, from your [definitions](/def). Callback payloads with a `$id` hoist into `# Common Events`. |
| `getExpressionsPartialPrompt({ maxLength?, note? })` | The `# JavaScript Expressions` block: syntax, methods, globals and the length limit, filled from [`@uicast/expr`](#uicastexpr)'s own tables. |
| `getFunctionsPartialPrompt({ functions, note? })` | Call signatures, from your [host functions](/expr/functions). |
| `getEditRequestPrompt({ request, missingKeys? })` | A user-turn message for an [edit](/prompt#edit-and-recovery-turns). |
| `getErrorRecoveryPrompt({ failures })` | A user-turn message naming the elements that failed. |

Types: one options type per builder (`ComponentsPromptOptions`,
`ScopePromptOptions`, …) and `RenderFailure`. `note?` is host text, rendered
verbatim as the section's trailing `## Note`.

## `@uicast/expr`

The [expression language](/expr).

| Export | What it does |
|---|---|
| `Evaluator` | The interpreter: `eval`, `compile`, `validate`, `memberReads`. `functions` binds [host functions](/expr/functions) at construction, so a call is checked before it runs; `budget` sets the limits. A subclass that sets `toFunction` runs expressions with `new Function` ([Custom evaluator](/expr/custom-expr)). |
| `ExpressionEvaluator` | The interface `Evaluator` implements and **uicast** types against: `eval`, `compile`, `validate`, `memberReads`, `functions`. Implement it to plug in an evaluator for another language. |
| `ExpressionError` | Every refusal and fault, with a `reason`. |

Types: `EvaluatorOptions`, `EvaluatorContexts`, `BudgetOptions`,
`ExpressionFacts`, `ExpressionErrorReason`, and `StandardToolV0` with
`StandardSchemaV1` / `StandardJSONSchemaV1`, copied verbatim from
`standard-tool` and the Standard Schema spec. A `standard-tool` tool fits as is.

`@uicast/expr/internal` is shared with core, with **no semver guarantee**.
Don't build on it.

## `@uicast/react`

Re-exports nothing from core — import from both.

| Export | What it does |
|---|---|
| `<RendererProvider>` | Holds the implementations, the evaluator (with host functions bound), fallback UI and the shared `root` scope. See [Renderer](/react/renderer). |
| `<EntriesRenderer entries>` | Mounts a document. Memoized on the array reference. |
| `createComponentImplementation({ def, render, placeholder? })` | The React half of a component pair: `{ def, placeholder }`, to register. See [impl](/react). |

Types: `ComponentImplementation`, `RenderContext`, `RendererProviderProps`,
`EntriesRendererProps`, `FallbackComponents`, `PlaceholderComponentProps`,
`ConfirmComponentProps`, `ErrorComponentProps`, `InitFn`, `InitContext`, `Scopes`.

## `@uicast/shadcn-catalog`

A reference catalog, usable as is. See
[Reference catalog](/react/reference-catalog).

| Entry point | What it holds |
|---|---|
| `@uicast/shadcn-catalog/all/defs` | Every definition by name (`CardDef`, `ButtonDef`, …), nothing else. Pass `Object.values` of `import * as` to `getComponentsPartialPrompt`. |
| `@uicast/shadcn-catalog/all/impls` | Every implementation by name (`CardImpl`, …), nothing else. Pass `Object.values` of `import * as` to `<RendererProvider>`. |
| `@uicast/shadcn-catalog/<group>/defs`, `/<group>/impls` | The same, one group each: `layout`, `content`, `data`, `charts`, `forms`, `navigation`, `overlays`. See [Reference catalog](/react/reference-catalog#groups). |
| `@uicast/shadcn-catalog/essential/defs`, `/essential/impls` | 30 of the 128, enough to build a page, at about a quarter of the prompt text. |
| `@uicast/shadcn-catalog/events` | `mouseEventSchema`, `keyboardEventSchema`: shared payloads the catalog's callbacks reuse. See [Shared events](/def#shared-events). |
| `@uicast/shadcn-catalog` | `ConfirmModal` and `RenderError`, for [`fallbackComponents`](/react/renderer). `DocumentSkeleton({ entries, implementations })`: gray placeholders in the shape of a document's tree. It evaluates nothing, so it renders anywhere, a server pass included. |
| `@uicast/shadcn-catalog/ui/*` | The 35 underlying shadcn components (`/ui/button`, `/ui/skeleton`, …). |
| `@uicast/shadcn-catalog/catalog.css` | Every utility the components use. No palette: your `@theme` supplies it. |
| `@uicast/shadcn-catalog/theme.css` | Optional baseline: preflight plus the shadcn palette. |

# Agent skill

**uicast** ships an [Agent Skill](https://agentskills.io): one
[`SKILL.md`](https://github.com/finom/uicast/tree/main/skills/uicast) for the
developer side — definitions and implementations, host functions, prompt
assembly, mounting, page and chat streaming, server rendering, errors and
security. The entry format the model emits is not in it; that comes from the
[assembled prompt](/prompt) at run time.

## Install

The [skills CLI](https://skills.sh) detects the agents you use and installs the
skill for each:

```sh
npx skills add finom/uicast
```

It supports Claude Code, Cursor, Codex, Gemini CLI, OpenCode, Copilot and most
other clients. To install by hand, copy the
[`skills/uicast`](https://github.com/finom/uicast/tree/main/skills/uicast)
folder to where your client looks for skills; the
[client showcase](https://agentskills.io/clients) links each client's setup
instructions.

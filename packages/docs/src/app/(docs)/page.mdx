# uicast

**uicast is a UI framework whose language is written by models, not people.**
It gives a language model what JSX gives a developer — components, state,
events — with every design choice flipped from *easy for a person to maintain*
to *reliable for a model to generate*.

An LLM emits one JSON object per line; the engine mounts each line in tree
order against a reactive state store, turning the stream into a complete,
interactive front-end app. You supply a pre-built **component catalog** to
render from and the **functions** the UI can call to load data, save changes,
and run actions. The emitted JSONLines are a static asset — serve them like a
regular HTML page, with no build or deploy step per generation.

What sets uicast apart is **expressions**. Frameworks in this space make the
model either write real code — expressive, but unpredictable and impossible to
trust without a sandbox — or fill a strict declarative schema — safe, but every
behavior must be built into the host ahead of time. uicast sits between: the
document is declarative JSONLines, while derived values, visibility, and event
handling are short JavaScript expressions, validated for safety and then run
against reactive scopes. The model writes the app's logic without writing the
app's code.

| Approach | Predictability | Expressiveness | Safety |
| --- | --- | --- | --- |
| Raw code generation | low | unlimited | low |
| **uicast** | high | high | high |
| Structured generation ([json-render](https://github.com/vercel-labs/json-render), [A2UI](https://a2ui.org)) | deterministic | limited | guaranteed |

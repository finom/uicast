# Roadmap

Where ui-fired is headed.

## Prompt-driven partial replacement

The runtime already supports [partial replacement](/entry/fields#key) — re-emit a
line with an existing `key` and the engine swaps that subtree in place. The only
missing piece is the prompt side: a generator function (or an option on the
existing prompt builder) that asks the model for a targeted re-emit, plus an
example. *Runtime: supported · prompt tooling: not started.*

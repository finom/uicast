# Roadmap

Where uicast is headed.

## Reactive `loading` placeholders

An element already shows a placeholder while an async
[`seed`](/entry/fields#seed) resolves. A planned `loading` field would extend
that to any condition: a bare [expression](/entry/expressions), evaluated like
[`hidden`](/entry/fields#hidden), showing the placeholder while truthy. Where
`hidden` toggles visibility, `loading` toggles the placeholder — a skeleton for
refreshing data, without unmounting anything. *Placeholder machinery exists;
schema, renderer and prompt: not started.*

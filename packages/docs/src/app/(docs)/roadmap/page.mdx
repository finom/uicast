# Roadmap

Where **uicast** is headed.

<Callout type="warning">
  uicast is an early-stage framework in beta — use it at your own risk. In
  particular, model-written expressions are evaluated in the browser behind a
  [guardrail, not a sandbox](/entry/expressions#safety) — read that page and
  decide whether the trade-off fits your app. The entry format and the prompt
  contract can also still change between releases.
</Callout>

## Reactive `loading` placeholders

A `loading` field on the entry: a bare [expression](/entry/expressions),
evaluated like [`hidden`](/entry/fields#hidden), showing the element's
[placeholder](/react/renderer) while truthy — a skeleton over refreshing data,
without unmounting anything.

## Pure host functions in reactive sites

An opt-in mark — `meta: { pure: true }` on the tool — declaring a host function
synchronous, deterministic, and effect-free. Marked functions become callable
in `props`, `hidden`, and `each`; unmarked ones stay rejected there.

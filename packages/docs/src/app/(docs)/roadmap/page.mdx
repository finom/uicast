# Roadmap

Where **uicast** is headed.

<Callout type="warning">
  uicast is an early-stage framework in beta — use it at your own risk.
  Model-written expressions run in the browser through an
  [interpreter with a closed grammar and a runtime membrane](/expr), not
  the JavaScript engine — a real language boundary, though host functions and
  what you inject into scope stay your responsibility. The entry format and the
  prompt contract can also still change between releases.
</Callout>

## Pure host functions in reactive sites

An opt-in mark — `meta: { pure: true }` on the tool — declaring a host function
synchronous, deterministic, and effect-free. Marked functions become callable
in `props`, `hidden`, and `each`; unmarked ones stay rejected there.

# Catalog gallery

Every component of the [reference catalog](/react/reference-catalog), rendered
from a small **uicast** document. **Props and source** opens controls that edit
the component's entry, and the entry as it would stream. A part, such as
`TableCell`, is a tab there. **Essential** limits the page to the
[essential group](/react/reference-catalog#groups).
